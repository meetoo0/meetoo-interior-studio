# MEETOO Interior Design Studio

The source code for the MEETOO studio portfolio website.

## Local development

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deployment

Import this repository into Vercel. The project uses Next.js and requires no environment variables for its initial build.

## Portfolio content

The initial site uses clearly labelled visual-direction imagery as temporary placeholders. Replace these with approved MEETOO project photographs and renders before presenting the site as a completed project portfolio.
